1 Overview

  • litedown, litedown-package: A lightweight version of R Markdown

2 Render documents

Convert Markdown and R Markdown to output formats.

  • html_format(), latex_format(): Output formats in YAML metadata
  • fuse(), fiss(), mark(): Render Markdown, R Markdown, and R scripts
  • markdown_options(): Markdown rendering options
  • roam(): Preview Markdown and R Markdown files
  • vest(): Add CSS/JS assets to HTML output

3 Code chunks and engines

Parse and run code chunks, and customize the runtime.

  • crack(), sieve(): Parse R Markdown or R scripts
  • engines(): Language engines
  • fuse_env(): The fuse() environment
  • fuse_exit(): Exit fuse() early
  • get_context(): Get the fuse() context
  • raw_text(): Mark a character vector as raw output
  • reactor(): Get and set chunk options
  • timing_data(): Get the timing data of code chunks and text blocks in a document

4 Websites and books

Build multi-page output and package sites.

  • fuse_book(): Fuse multiple R Markdown documents to a single output file
  • fuse_site(): Fuse R Markdown documents individually under a directory
  • pkg_desc(), pkg_news(), pkg_code(), pkg_examples(), pkg_citation(), pkg_manual(), pkg_articles(): Print the package description, news, citation, manual pages, and source code
  • pkg_site(): Build a website for an R package
